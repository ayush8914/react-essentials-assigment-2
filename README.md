# 📋 Task Manager App

A modern **Task Management Application** built with **React + TypeScript** that allows users to create, organize, and manage tasks efficiently.  
The app supports task prioritization, filtering, undo functionality, and a clean responsive UI.

---

## 🚀 Features

- ✅ Create new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete individual tasks
- 🧹 Delete all tasks
- ✔️ Mark tasks as completed
- 🔄 Undo last task action
- 🏷️ Task priority levels (Low / Medium / High)
- 📂 Filter tasks (All / Completed / Pending)
- 🎨 Clean and responsive UI
